JustVoxel — спеціалізована система для самостійного розміщення серверів Minecraft. Встановіть її на сумісний ПК, ноутбук, фізичний сервер, віртуальну машину або на хостингу, що дозволяє використовувати власний образ ОС. Після цього керуйте Minecraft із браузера.

Вам не доведеться підтримувати набір скриптів чи окремо встановлювати панель керування Minecraft.

Маєте старий ноутбук або ПК? **Завдяки JustVoxel HWS обладнання, яке лежить без діла, може стати виділеним сервером Minecraft.** На підтримуваних ноутбуках можна вимкнути перехід у режим сну при закритті кришки, щоб сервер продовжував працювати. Екран локальної консолі можна вимкнути одразу або з невеликою затримкою.

> 🚧 **Попередня версія.** JustVoxel готують до першого публічного випуску. Поточний інсталяційний ISO-образ доступний для тестування й раннього використання, поки триває остаточна перевірка випуску.

## ✨ Простіший хостинг Minecraft

JustVoxel поєднує засоби керування Minecraft з операційною системою, на якій працюють сервери.

- 🎮 **Кілька серверів Minecraft** — запускайте різні світи й типи серверів незалежно один від одного на одному пристрої.
- 🖥️ **Вебцентр керування** — керуйте серверами з комп’ютера, планшета чи телефона.
- 🧩 **Плагіни й моди** — знаходьте сумісні доповнення в підтримуваних каталогах і керуйте ними.
- 💾 **Резервне копіювання й відновлення** — захищайте кожен сервер, створюючи копії за розкладом і вручну.
- 🌐 **Віддалений доступ** — вибирайте з чотирьох вбудованих варіантів для приватного доступу й ігрових тунелів.
- 🤖 **ШІ й автоматизація** — підключайте сумісних ШІ-помічників і застосунки через MCP та REST.
- 💬 **Telegram і Discord** — за бажанням керуйте серверами через ботів, отримуйте сповіщення й організовуйте взаємодію зі спільнотою.
- 🛡️ **Керування системою** — налаштовуйте мережу та сховище, керуйте оновленнями, перевіряйте стан системи й журнали та виконуйте підтримувані дії з живленням без знання команд Linux.

JustVoxel створено для родин, друзів, невеликих спільнот Minecraft і всіх, хто хоче мати власний сервер замість оренди традиційної панелі Minecraft-хостингу.

## 🖥️ Одна система, дві редакції

### JustVoxel VM

Для віртуальних машин і хостингових середовищ, зокрема:

- Proxmox
- KVM / libvirt
- VMware
- Hyper-V
- VirtualBox
- віртуальних машин у хостинг-провайдерів або VPS, де можна використовувати сумісний власний образ ОС

Редакція VM містить повну систему для Minecraft без пакетів для фізичного обладнання, які не потрібні у віртуальній машині.

### JustVoxel HWS

Для встановлення безпосередньо на фізичне обладнання, зокрема:

- старий ноутбук
- настільний ПК, якому ви знайшли нове застосування
- міні-ПК
- домашній сервер
- орендований виділений фізичний сервер, де дозволено власні інсталяційні носії

HWS додає підтримку фізичного обладнання: інтеграцію з ДБЖ через NUT, інструменти SMART і NVMe, роботу з датчиками, керування вбудованим ПЗ та UEFI, прошивки пристроїв, діагностику обладнання й налаштування екрана та поведінки ноутбука при закритті кришки.

Обидві редакції мають однаковий центр керування JustVoxel, Management API, засоби роботи з Minecraft, модель зберігання даних, резервне копіювання, мережеві можливості та порядок оновлення.

## 🚀 Встановлення JustVoxel

Один інсталяційний ISO-образ підтримує обидві редакції JustVoxel.

[⬇️ Завантажити ISO-образ JustVoxel для x86_64](https://sourceforge.net/projects/justvoxel/files/JustVoxel-x86_64.iso/download)

Виберіть редакцію відповідно до місця встановлення:

- **JustVoxel VM** — для віртуальних машин, зокрема в сумісних хостингових середовищах
- **JustVoxel HWS** — для ПК, ноутбуків, міні-ПК, фізичних домашніх серверів і сумісних виділених фізичних серверів на хостингу

Підготовку диска, встановлення й перший вхід описано в [посібнику зі встановлення](../docs/INSTALLER.md).

## 🏠 Насамперед для Minecraft, але й для інших завдань

JustVoxel розробляють і підтримують передусім як готову систему для серверів Minecraft. В її основі — звичайний **сервер AlmaLinux 10 bootc із Podman, Quadlet, systemd, SSH, NetworkManager і стандартними інструментами адміністрування Linux**.

Досвідчені користувачі можуть використовувати ту саму машину як багатофункціональний домашній сервер і запускати додаткові контейнери поруч із Minecraft.

Наприклад, вручну можна розгорнути такі сервіси:

- **Jellyfin** або **Plex** для медіатеки
- **Vaultwarden** для керування паролями
- **Immich** для впорядкування фото й відео
- **Home Assistant Container** для домашньої автоматизації
- **Nextcloud** для роботи з файлами та спільної роботи
- **Syncthing** або **Navidrome**
- **OpenClaw** як ШІ-агент або шлюз на власному сервері

Центр керування JustVoxel **не керує цими застосунками**. За їхні контейнери Podman, файли Quadlet, сховище, порти, оновлення, резервні копії, налаштування зворотного проксі й дотримання вимог кожного застосунку відповідає адміністратор.

JustVoxel свідомо обмежує свою роль керуванням системою Minecraft. Для решти завдань досвідчені користувачі можуть працювати з Podman і Quadlet звичним способом.

Під час обслуговування JustVoxel також розглядає сторонні контейнери як окремі сервіси адміністратора. Зокрема, операція Minecraft **«Почати спочатку» (Start Over)** не видаляє сторонні контейнери Podman.

Отже, машина з JustVoxel може залишатися насамперед сервером Minecraft і за бажанням водночас виконувати роль звичайного домашнього сервера з контейнерами.

## 🎮 Створіть потрібний вам сервер Minecraft

JustVoxel може одночасно запускати кілька незалежних серверів Minecraft, якщо на машині достатньо пам’яті й вільних портів.

Кожен сервер має власний ідентифікатор, конфігурацію, середовище виконання, порти, дані, резервні копії, засоби керування життєвим циклом і окремий стан.

### Підтримуване серверне ПЗ

| Серверне ПЗ | Тип доповнень | Спільна гра Java → Bedrock під керуванням JustVoxel |
| --- | --- | --- |
| **Paper** | Плагіни | ✅ |
| **Purpur** | Плагіни | ✅ |
| **Spigot** | Плагіни | ✅ |
| **Pufferfish** | Плагіни | ✅ |
| **Leaf** | Плагіни | ✅ |
| **Fabric** | Моди | ✅ Якщо підтверджено сумісність конкретних версій |
| **NeoForge** | Моди | ✅ Якщо підтверджено сумісність конкретних версій |
| **Forge** | Моди | Лише Java |
| **Quilt** | Моди | Лише Java |
| **Vanilla Java** | Без плагінів і модів | Лише Java |
| **Native Bedrock** | Власне серверне ПЗ Bedrock | Клієнти Bedrock |

Для покрокового створення першого сервера виберіть **просте налаштування (Simple Setup)**. Виберіть **розширене налаштування (Advanced Setup)**, якщо хочете самостійно налаштувати пам’ять, порти, сховище, резервні копії, правила вибору версій і спільну гру між сумісними виданнями.

JustVoxel перевіряє, які функції справді підтримує вибране серверне ПЗ.

[Докладніше про серверне ПЗ та сумісність](../docs/server-software.md)

## 🧩 Плагіни й моди

Для вибраного сервера відкрийте **Minecraft → Плагіни й моди**.

Залежно від типу сервера JustVoxel може використовувати такі каталоги:

- [Modrinth](https://modrinth.com/)
- [Hangar](https://hangar.papermc.io/)
- [CurseForge](https://www.curseforge.com/minecraft) із налаштованим вами ключем API

Під час встановлення підтримуваних доповнень JustVoxel перевіряє сумісність і завантажені файли, створює резервні копії зупиненого сервера, перевіряє результат перезапуску, відстежує належність компонентів і передбачає засоби відновлення.

Сервери сімейства Paper можуть використовувати каталоги плагінів. Fabric, Forge, NeoForge та Quilt працюють із каталогами модів і перевіряють точну відповідність завантажувача та версії Minecraft. Для Vanilla Java й оригінального сервера Bedrock каталог плагінів чи модів навмисно не передбачено.

[Докладніше про плагіни й моди](../docs/plugin-workspace.md)

## 🌐 Додаткова можливість Minecraft Network

Кілька серверів цілком можуть працювати незалежно. Проксі для цього **не потрібен**.

Якщо ви хочете надати гравцям одну публічну адресу для входу на кілька сумісних серверів, у JustVoxel можна налаштувати **Minecraft Network** на основі Velocity.

У центрі керування можна вибрати підтримувані сервери за проксі, налаштувати публічні порти Java та Bedrock, керувати віртуальним лобі, вітальним повідомленням і складом мережі.

Minecraft Network підтримує Paper, Purpur, Pufferfish і Leaf як сервери за проксі. Сервери Fabric/Quilt і Forge/NeoForge також можуть долучатися, якщо JustVoxel підтвердить потрібну сумісність із проксі. Spigot, Vanilla та оригінальний сервер Bedrock працюють окремо.

[Докладніше про Minecraft Network](../docs/minecraft-network.md)

## 🖥️ Знайомство з центром керування

Інтерфейс JustVoxel побудовано навколо повсякденних серверних завдань, тож вам не потрібно розбиратися у внутрішній будові Linux.

### Сервери Minecraft

Створюйте кілька серверів і керуйте кожним окремо: запускайте й зупиняйте їх, перевіряйте стан і список гравців, змінюйте підтримувані налаштування та користуйтеся інструментами для конкретного сервера.

### Плагіни й моди

Знаходьте сумісні доповнення, переглядайте встановлені плагіни й моди та керуйте підтримуваними доповненнями. Якщо після зміни потрібне втручання, тут можна переглянути відомості про відновлення.

### Резервні копії та сховище

Створюйте резервні копії, переглядайте їхню історію, відновлюйте всі дані сервера, вибирайте місця зберігання копій, імпортуйте й експортуйте сервери та керуйте підтримуваними сховищами.

### Мережа

Керуйте Ethernet, Wi-Fi і віддаленим доступом та користуйтеся засобами **діагностики проблем зі з’єднанням**. Для змін, які можуть перервати з’єднання, передбачено відкат. Це дає змогу відновити доступ, якщо ви помилилися в IP-адресі чи налаштуваннях Wi-Fi.

### Система

Перевіряйте стан системи, ресурси, журнали й оновлення ОС. Тут також доступні налаштування користувачів і безпеки, підтримувані дії з живленням, а в редакції HWS — засоби керування обладнанням.

### Підключення ШІ та API

Підключайте підтримувані ШІ-застосунки, клієнти MCP, засоби автоматизації через REST, Telegram і Discord без розгортання окремої системи керування.

Віддаєте перевагу терміналу? JustVoxel також містить **mjust** — інтерактивний термінальний інтерфейс адміністрування, у якому діють ті самі правила безпеки.

[Документація вебінтерфейсу](../docs/WEBUI.md) · [Посібник із mjust](../docs/MJUST.md)

## 🌐 Виберіть, як друзі підключатимуться до гри

Наразі JustVoxel пропонує чотири варіанти в розділі **Мережа → Віддалений доступ**.

Для сервісів, вбудованих в образ, JustVoxel надає засоби перегляду стану, увімкнення, вимкнення й налаштування відповідно до можливостей кожного провайдера.

| Сервіс | Для чого підходить | Що ви отримуєте |
| --- | --- | --- |
| **[Tailscale](https://tailscale.com/)** | Приватні сервери для друзів і родини | Приватна mesh-мережа між схваленими пристроями |
| **[NetBird](https://netbird.io/)** | Приватні мережі з керованим доступом | Приватна мережа з керуванням обліковими записами та правилами доступу |
| **[Playit.gg](https://playit.gg/)** | Публічний доступ до Minecraft без звичайного перенаправлення портів на маршрутизаторі | Публічні ігрові тунелі й адреси для підключення |
| **[NordVPN Meshnet](https://meshnet.nordvpn.com/)** | Приватні з’єднання між пристроями користувачів NordVPN | З’єднання через Meshnet без використання JustVoxel як клієнта комерційного VPN |

### Що вибрати?

**🎮 Хочете, щоб друзі могли приєднатися без встановлення клієнта приватної VPN?**  
Зверніть увагу на **Playit.gg**. Гравці зможуть скористатися публічною адресою налаштованого вами ігрового тунелю.

**🔒 Потрібен приватний сервер для довірених пристроїв?**  
Розгляньте **Tailscale** або **NetBird**.

**🌍 Уже користуєтеся NordVPN Meshnet?**  
JustVoxel може керувати підключенням до Meshnet. Це окрема можливість, незалежна від підключення пристрою до звичайного вихідного сервера комерційної мережі NordVPN.

Облікові записи, хмарні правила доступу та конфігурація тунелів залишаються на боці провайдера. JustVoxel відповідає за підтримувані налаштування на вашому пристрої.

Можна одночасно користуватися кількома VPN або mesh-мережами, але їхні маршрути, налаштування DNS чи правила брандмауера можуть конфліктувати.

[Посібник із мережі й віддаленого доступу](../docs/NETWORKING.md)

## 🤖 ШІ, MCP, REST та автоматизація

Хочете запитати ШІ-помічника про стан сервера, підключити домашню автоматизацію або створити власний сценарій керування?

JustVoxel надає вбудовані **інтерфейси MCP і REST** у розділі **Підключення ШІ та API**.

Під час налаштування можна вибрати сумісний застосунок або тип підключення:

- **OpenAI — ChatGPT і Codex**
- **Claude**
- **Grok**
- **Gemini**
- **GitHub Copilot**
- **Інший застосунок ШІ / MCP**
- **Автоматизація / REST API**

Ви визначаєте, до чого матиме доступ кожне підключення.

Права охоплюють **рівень 1 — лише читання**, керування серверами й, тільки за явною згодою, розширене керування системою. Для окремого підключення можна обмежити доступ вибраними серверами Minecraft.

Щоб надати доступ до інтерфейсу MCP або REST, JustVoxel не потребує ключа API моделі ШІ. Можливість підключення конкретного клієнта залежить від застосунку, можливостей облікового запису чи передплати й доступу до мережі.

Шлюз ШІ та API початково вимкнено. Ви самі вирішуєте, коли його ввімкнути.

## 💬 Telegram і Discord

У JustVoxel за бажанням можна ввімкнути вбудовані інтеграції з Telegram і Discord. Вони використовують ту саму серверну службу, що й вебінтерфейс, і саме ця служба відповідає за виконання операцій керування.

### Telegram

Спеціальний Telegram-бот дає змогу:

- перевіряти стан пристрою та Minecraft
- вибирати сервер і переглядати відомості про гравців
- запускати, зупиняти й перезапускати сервер за наявності прав керування
- створювати резервні копії вручну
- переглядати оновлення Minecraft і контейнерів
- отримувати відомості про оновлення ОС
- керовано перезавантажувати систему
- за бажанням отримувати сповіщення про стан сервера, результати резервного копіювання й доступні оновлення

Для Telegram діють окремі права **«Лише читання»** та **«Керування серверами»**. Модель ШІ для роботи бота не потрібна.

[Налаштування Telegram і права доступу](../docs/TELEGRAM.md)

### Discord

Через Discord із Minecraft можуть взаємодіяти як учасники спільноти, так і адміністратори.

Учасники сервера Discord, який адміністратор явно прив’язав до JustVoxel, можуть переглядати основні відомості про стан сервера Minecraft і запитувати доступ до гри. Права адміністратора при цьому не надаються автоматично.

Уповноважені адміністратори JustVoxel у Discord можуть запускати, зупиняти й перезапускати сервери, створювати резервні копії вручну, переглядати оновлення, керувати Minecraft Network та виконувати інші підтримувані розширені дії.

Участь у сервері Discord, доступ до Minecraft за списком дозволених гравців і права адміністратора JustVoxel надаються окремо.

[Налаштування Discord, доступ для спільноти й адміністрування](../docs/DISCORD.md)

## 💾 Резервні копії, відновлення, сховище й перенесення

Дані Minecraft важливіші за образ системи.

JustVoxel зберігає дані Minecraft і резервні копії поза розгорнутою незмінною ОС. Місце зберігання для даних і для копій можна вибрати окремо.

Підтримувані варіанти зберігання:

- системна файлова система
- окремі внутрішні диски
- USB-накопичувачі
- наявні локальні розділи й файлові системи
- нові розділи, створені з уже нерозподіленого простору
- NFS
- SMB/CIFS

Для кожного сервера можна створювати резервні копії автоматично й вручну. Під час відновлення JustVoxel замінює всі постійні дані вибраного сервера, зберігаючи його ідентифікатор і конфігурацію в JustVoxel.

Щоб перенести сервер на іншу машину або повернути його після перевстановлення, JustVoxel також пропонує процедури **експорту, імпорту й відновлення** з попереднім переглядом дій.

[Сховище](../docs/STORAGE.md) · [Відновлення](../docs/RESTORE.md) · [Перенесення](../docs/MIGRATION.md)

## 🛡️ Безпечніше внесення змін

За вебінтерфейсом JustVoxel стоїть система, яка контролює виконання дій. Сторінка не запускає довільних команд оболонки.

Для підтримуваних операцій діють такі правила захисту:

- перевірка присутності гравців перед діями, що можуть перервати гру
- попередній перегляд змін перед застосуванням
- резервне копіювання зупиненого сервера, якщо після зміни може знадобитися відновлення
- точна ідентифікація сервера, щоб випадково не підмінити один сервер іншим
- перевірка перезапуску й роботи сервера
- збереження стану операцій і відновлення
- можливість відкотити підтримувані операції
- контрольні точки NetworkManager для ризикованих змін мережі
- окремі процедури оновлення Minecraft та операційної системи

Вебінтерфейс, доступний із браузера, працює без привілеїв адміністратора. Привілейовані зміни виконує локальний агент керування JustVoxel Management Agent через чітко визначений API. Браузер не отримує доступу до командної оболонки root.

## 🔄 Оновлення системи окремо від оновлень Minecraft

JustVoxel — система на основі Home Server Base 10 / AlmaLinux 10, що оновлюється за допомогою образів.

Операційна система оновлюється окремо від версій Minecraft, серверного ПЗ, плагінів, модів і контейнерів.

Тому оновлення системи не призведе до непомітної зміни версії Minecraft, а зміни на сервері Minecraft не потребують повторного збирання ОС хоста.
